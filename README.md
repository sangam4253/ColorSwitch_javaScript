# ColorSwitch - A Simple Background Color Switcher

ColorSwitch is a lightweight JavaScript project designed to dynamically change the background color of a webpage with a single click. This repository is perfect for beginners learning JavaScript or developers looking for a quick color-changing tool.

## Features

- Click-to-change background color.
- Random color generation.
- Lightweight and easy-to-implement code.
- Fully responsive and works on all modern browsers.
